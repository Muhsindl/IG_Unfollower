# 🚀 IG Unfollower

Instagram’da sizi geri takip etmeyen kullanıcıları tespit eden, listeleyen ve isteğe bağlı olarak toplu takipten çıkarma işlemi yapabilen gelişmiş bir browser console scripti.

Cyberpunk / Glassmorphism tasarım anlayışıyla hazırlanmıştır.
Türkçe 🇹🇷 ve İngilizce 🇺🇸 dil desteği içerir.

---

# ✨ Özellikler

* ✅ Takip etmeyenleri hızlı tarama
* ✅ Modern Cyberpunk / Glassmorphism arayüz
* ✅ Türkçe & İngilizce dil desteği
* ✅ Kullanıcı filtreleme sistemi
* ✅ Gizleme / tekrar gösterme özelliği
* ✅ Toplu seçim sistemi
* ✅ Otomatik unfollow işlemi
* ✅ Güvenli gecikme sistemi
* ✅ Pause / Resume desteği
* ✅ Instagram rate-limit koruması
* ✅ Profil açma & kullanıcı adı kopyalama
* ✅ Ayarlanabilir hız ve bekleme süreleri

---

# ⚠️ Uyarı

Bu proje yalnızca eğitim ve kişisel kullanım amacıyla paylaşılmıştır.

Instagram’ın kullanım politikalarına aykırı veya aşırı kullanım durumunda hesabınız geçici olarak kısıtlanabilir.

Kullanım tamamen kullanıcı sorumluluğundadır.

---

# 🛠️ Nasıl Kullanılır?

## 1️⃣ Instagram’a Giriş Yapın

Tarayıcı üzerinden:

```txt
https://www.instagram.com
```

adresine giriş yapın.

---

## 2️⃣ Developer Console Açın

### Windows / Linux

```txt
F12
```

veya

```txt
CTRL + SHIFT + I
```

### macOS

```txt
CMD + OPTION + I
```

---

## 3️⃣ Console Sekmesine Geçin

Açılan geliştirici araçlarından:

```txt
Console
```

sekmesini açın.

---

## 4️⃣ Script Kodunu Yapıştırın

Repository içerisindeki:

```txt
ig_unfollower.js
```

dosyasının içeriğini tamamen kopyalayın.

Console alanına yapıştırıp:

```txt
ENTER
```

tuşuna basın.

---

## 5️⃣ Tarama Başlatın 🚀

Script otomatik olarak arayüzü açacaktır.

Buradan:

* Takip etmeyenleri tarayabilir
* Sonuçları filtreleyebilir
* Kullanıcıları seçebilir
* Toplu unfollow işlemi başlatabilirsiniz

---

# 🧠 Güvenlik Sistemi

Script, Instagram’ın istek limitlerine takılmamak için:

* Rastgele gecikmeler
* Cooldown süreleri
* Sayfa bazlı bekleme sistemi

kullanmaktadır.

Daha güvenli kullanım için ayarlar bölümünden süreleri artırabilirsiniz.
